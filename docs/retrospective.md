What Went Well (Apa yang berjalan baik)
-
- Tim berhasil menjaga fokus ke fitur inti SpotRent: login, pencarian properti, detail properti, booking, pembayaran, dan penambahan properti oleh mitra.
- Tim berhasil menentukan arah project dengan jelas: platform penyewaan lokasi/properti untuk kebutuhan syuting.
- Fitur-fitur major sudah terdefinisi dengan baik, seperti login, pencarian properti, detail properti, booking, pembayaran, dan tambah properti.
- Alur kebutuhan sudah cukup jelas dari dokumen backlog, user story, dan problem statement, jadi pengembangan lebih terarah.
- Koordinasi antar role user, mitra, dan admin tergambar rapi sehingga scope produk tidak melebar.
- Dokumentasi project cukup lengkap sehingga memudahkan semua anggota memahami kebutuhan sistem.
- Komunikasi antar tim tetap terjaga dengan baik dari awal project berlangsung hingga akhir masa project berjalan
- Project punya value yang jelas karena menyasar kebutuhan spesifik industri kreatif.
- Struktur fitur terlihat konsisten dari kebutuhan sampai implementasi.
- Tim bisa menjaga fokus agar project tidak melebar ke fitur yang tidak terlalu relevan.

What Did'nt Go Well (Apa yang tidak berjalan baik)
-
- Scope fitur berpotensi terasa terlalu luas kalau tidak dibatasi ke MVP.
- Ada beberapa keputusan teknis diambil terlambat karena diskusi scope belum cukup cepat.
- Beberapa branches tidak di-merge tepat waktu sehingga terdapat error work.
- Beberapa meeting online tidak lengkap anggotanya dikarenakan kesibukan masing-masing anggota tim.
- Kepadatan aktifitas masing-masing anggota saat project sedang berlangsung.

What Can We Improve (Apa yang bisa diperbaiki ke depan)
-
- Tambahkan checkpoint rutin untuk mengecek apakah backlog, user story, dan implementasi masih sinkron.
- Beberapa alur penting seperti booking dan pembayaran masih berpotensi butuh detail yang lebih matang (karena sejauh ini masih menggunakan simulasi)
- Menjaga scope tetap realistis sesuai waktu dan kapasitas tim.
- Mencatat keputusan penting selama pengerjaan supaya tidak diulang-ulang.
