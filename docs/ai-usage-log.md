## Refleksi Penggunaan AI

Secara umum, penggunaan alat bantu AI sangat membantu tim dalam menyusun rancangan awal struktur kode, serta membuat maupun memperbaiki tampilan-tampilan visual skala kecil di website (seperti penyesuaian UI, penambahan tombol konfirmasi, dan pembersihan warning CSS). Namun, AI terbukti mengalami kesulitan jika langsung diminta untuk membuat fitur baru yang lumayan kompleks secara mandiri. AI harus terlebih dahulu diberikan konteks sistem yang lebih detail, alur relasi database, dan aturan bisnis secara spesifik barulah ia dapat membantu menyelesaikan logika fitur-fitur yang kompleks tersebut secara optimal.


### Apa yang Berhasil

1. **Penyusunan Kerangka Kode Cepat:** AI sangat efektif untuk memicu produktivitas awal dalam pembuatan boilerplate, database migrations, model Eloquent, serta struktur dasar routing di Laravel secara rapi dan cepat.
2. **Penyelesaian Logika Pembanding & Validasi Kustom:** Logika penanganan waktu tumpang tindih (*overlapping dates*) dan pemrosesan validasi teks berbasis Regular Expression (regex) berhasil diselesaikan secara akurat tanpa *trial-and-error* yang lama.
3. **Refactoring & Modularisasi JavaScript:** Panduan pembagian berkas JS dashboard admin yang gemuk menjadi modul-modul modular (`users.js`, `comments.js`, dll) mempermudah tim dalam membaca alur kode (*maintainability*).

### Apa yang Tidak Berhasil / Gagal

1. **Keterbatasan Informasi Konfigurasi Runtime Server:** AI tidak mengetahui batasan default file upload PHP lokal (`2MB`) pada masing-masing mesin komputer developer. AI sempat merekomendasikan edit manual file `php.ini` secara global sebelum tim berinisiatif melakukan intercept otomatis via custom command di file `artisan` proyek.
2. **Sinkronisasi Desain Visual & Viewport:** Saat membuat fitur atur posisi thumbnail gambar (*image cropping*), saran kode posisi relatif AI sempat meleset secara visual karena AI tidak bisa melihat perbedaan aspek rasio antara kotak preview dan tampilan detail properti nyata. Tim harus meriset mandiri aspek rasio yang sama untuk menyelaraskannya.
3. **Ketidaksesuaian Logika Bisnis Kompleks (Data Overlapping):** AI kesulitan memahami model data relasi di mana pengguna dapat memiliki beberapa peran aktif sekaligus (multi-role). Hal ini sempat memicu data statistik pengguna ganda di admin dashboard sebelum diperbaiki menggunakan logika peran utama (`primary_role`).
